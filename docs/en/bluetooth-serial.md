# Bluetooth Serial

*Plugin: Bluetooth Serial.* Pair a Bluetooth serial adapter once, for example a wireless
replacement for the EQMOD cable, then pick it by name from any driver that supports Bluetooth
(such as [EQMOD](eqmod.md)).

1. Switch the adapter on and click **Scan**. Nearby devices are listed.
2. Click **Pair** next to yours. Enter its **PIN** if asked (often `1234` or `0000`) and
   **Confirm**.
3. It appears under **Paired devices**. **Rename** it to something meaningful (*Mount BT*);
   **Forget** removes it (drivers using it will need it paired again).

Then select it on the driver's page, for example *Connect over Bluetooth* on the
[EQMOD](eqmod.md#connect-over-bluetooth) page.
