astrolol apt repository

Packages of astrolol for Debian 13, Raspberry Pi OS (trixie) and Ubuntu 26.04.

sudo curl -fsSL https://apt.astrolol.lol/astrolol.gpg -o /etc/apt/keyrings/astrolol.gpg
sudo tee /etc/apt/sources.list.d/astrolol.sources <<'EOF'
Types: deb
URIs: https://apt.astrolol.lol
Suites: nightly
Components: main
Signed-By: /etc/apt/keyrings/astrolol.gpg
EOF
sudo apt update
sudo apt install astrolol

Then open http://<this computer>:8000 in a browser.

Only nightly builds for now: they follow the development branch.
