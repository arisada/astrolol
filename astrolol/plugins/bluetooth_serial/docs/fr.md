# Bluetooth série

*Module : Bluetooth série.* Appairez une fois un adaptateur Bluetooth série, par exemple un
remplacement sans fil du câble EQMOD, puis choisissez-le par son nom dans tout pilote compatible
Bluetooth (comme [EQMOD](../../eqmod/docs/fr.md)).

1. Allumez l'adaptateur et cliquez sur **Rechercher**. Les appareils à proximité s'affichent.
2. Cliquez sur **Appairer** à côté du vôtre. Saisissez son **PIN** si on vous le demande (souvent
   `1234` ou `0000`) et **Valider**.
3. Il apparaît sous **Appareils appairés**. **Renommer** pour lui donner un nom parlant
   (*Monture BT*) ; **Oublier** le retire (les pilotes qui l'utilisent devront le réappairer).

Choisissez-le ensuite sur la page du pilote, par exemple *Connexion par Bluetooth* sur la page
[EQMOD](../../eqmod/docs/fr.md#connexion-par-bluetooth).
